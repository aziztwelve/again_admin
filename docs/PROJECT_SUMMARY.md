# Project Summary

Кратко: фронтенд админ‑панели/дашборда для проекта Again (есть ссылки на `again8.ru`).

Основное по структуре и функционалу:
- Аутентификация и доступ к админ‑разделам (`/auth`, `/auth/logout`).
- Дашборд и аналитика.
- Заказы: список, создание, обновление, задачи.
- Товары: список, онлайн‑каталог, импорт, редактирование, отзывы, цены и остатки.
- Категории, клиенты и скидки, доставки.
- Склад/производство/рецептуры/материалы.
- Пользователи, профиль, настройки.
- Интеграции (в т.ч. Telegram/Email/MoySklad по названиям модулей).

Ключевые файлы для ориентира:
- Маршруты: `src/router/index.js`
- Разделы приложения: `src/views/*`
- Дашборд: `src/views/dashboard/DashboardView.vue`, `src/components/dashboard/*`
- API и админ‑контекст: `src/api/authApi.js`, `src/composables/*`
