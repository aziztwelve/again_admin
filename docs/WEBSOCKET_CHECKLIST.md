## 🐛 Troubleshooting Checklist

### Проблема: Сообщения не приходят

- [ ] Проверить консоль на ошибки
- [ ] Проверить `window.Echo` в консоли
- [ ] Проверить состояние подключения: `window.Echo.connector.pusher.connection.state`
- [ ] Проверить имя канала (должно быть `conversation.{id}`)
- [ ] Проверить, что сервер отправляет события
- [ ] Проверить права доступа к каналу

### Проблема: Дубликаты сообщений

- [ ] Проверить, что не смешивается старая и новая логика
- [ ] Проверить логику проверки дубликатов в `useWebSocketMessages`
- [ ] Проверить, что используется `setMessages` вместо прямого push
- [ ] Проверить, что нет нескольких подписок на один канал

### Проблема: Индикатор печати не работает

- [ ] Проверить, что сервер отправляет событие `UserTyping`
- [ ] Проверить формат события в консоли
- [ ] Проверить, что таймер работает (3 секунды)
- [ ] Проверить, что `clearAllTyping` вызывается при отписке

### Проблема: Статусы не обновляются

- [ ] Проверить, что сервер отправляет `MessageStatusUpdated`
- [ ] Проверить, что `message_id` совпадает с ID в списке
- [ ] Проверить формат события
- [ ] Проверить, что `useWebSocketStatus` правильно обновляет статус

### Проблема: Высокое потребление памяти

- [ ] Ограничить количество сообщений в памяти (500-1000)
- [ ] Реализовать виртуализацию списка
- [ ] Очищать старые сообщения при загрузке новых
- [ ] Проверить, что таймеры очищаются
