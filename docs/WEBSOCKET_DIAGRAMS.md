## 🔄 Поток данных при получении сообщения

```
1. Сервер отправляет событие
   ┌─────────────────────────────────────┐
   │ Laravel: broadcast(MessageCreated)  │
   └──────────────┬──────────────────────┘
                  │
                  ↓ WebSocket
   ┌─────────────────────────────────────┐
   │ Reverb Server                       │
   └──────────────┬──────────────────────┘
                  │
                  ↓ wss://
   ┌─────────────────────────────────────┐
   │ Browser: window.Echo                │
   └──────────────┬──────────────────────┘
                  │
                  ↓ .listen()
   ┌─────────────────────────────────────┐
   │ useConversationWebSocket            │
   │   handleMessageCreated()            │
   └──────────────┬──────────────────────┘
                  │
                  ↓
   ┌─────────────────────────────────────┐
   │ useWebSocketMessages                │
   │   addMessage()                      │
   └──────────────┬──────────────────────┘
                  │
                  ↓ проверка дубликатов
   ┌─────────────────────────────────────┐
   │ messages.value.push(newMessage)     │
   └──────────────┬──────────────────────┘
                  │
                  ↓ callback
   ┌─────────────────────────────────────┐
   │ onMessageReceived(message)          │
   └──────────────┬──────────────────────┘
                  │
                  ↓
   ┌─────────────────────────────────────┐
   │ Component:                          │
   │ • Прокрутка вниз                    │
   │ • Воспроизведение звука             │
   │ • Показ уведомления                 │
   │ • Обновление UI                     │
   └─────────────────────────────────────┘
```

## 📨 Поток данных при отправке сообщения

```
1. Пользователь вводит текст и нажимает Enter
   ┌─────────────────────────────────────┐
   │ Component: sendMessage()            │
   └──────────────┬──────────────────────┘
                  │
                  ↓ создание временного сообщения
   ┌─────────────────────────────────────┐
   │ tempMessage = {                     │
   │   id: 'temp-123',                   │
   │   status: 'sending',                │
   │   ...                               │
   │ }                                   │
   └──────────────┬──────────────────────┘
                  │
                  ↓ добавление в UI
   ┌─────────────────────────────────────┐
   │ setMessages([...messages, temp])    │
   └──────────────┬──────────────────────┘
                  │
                  ↓ API запрос
   ┌─────────────────────────────────────┐
   │ conversationReplyById()             │
   └──────────────┬──────────────────────┘
                  │
                  ↓ POST /api/conversations/{id}/reply
   ┌─────────────────────────────────────┐
   │ Laravel Backend                     │
   │ • Сохранение в БД                   │
   │ • Broadcast MessageCreated          │
   └──────────────┬──────────────────────┘
                  │
                  ↓ response
   ┌─────────────────────────────────────┐
   │ realMessage = { id: 456, ... }      │
   └──────────────┬──────────────────────┘
                  │
                  ↓ замена временного на реальное
   ┌─────────────────────────────────────┐
   │ messages.map(m =>                   │
   │   m.id === 'temp-123'               │
   │     ? realMessage                   │
   │     : m                             │
   │ )                                   │
   └──────────────┬──────────────────────┘
                  │
                  ↓ WebSocket событие приходит другим клиентам
   ┌─────────────────────────────────────┐
   │ Другие пользователи получают        │
   │ MessageCreated через WebSocket      │
   └─────────────────────────────────────┘
```

## 🔌 Управление подключением

```
┌─────────────────────────────────────────────────────────┐
│                    Component Mount                       │
└────────────────────────┬────────────────────────────────┘
                         │
                         ↓
┌─────────────────────────────────────────────────────────┐
│  useConversationWebSocket({ conversationId })           │
└────────────────────────┬────────────────────────────────┘
                         │
                         ↓
┌─────────────────────────────────────────────────────────┐
│  watch(conversationId, (newId, oldId) => {              │
│    if (oldId) unsubscribe(oldId)                        │
│    if (newId) subscribe(newId)                          │
│  })                                                      │
└────────────────────────┬────────────────────────────────┘
                         │
        ┌────────────────┴────────────────┐
        │                                 │
        ↓ subscribe                       ↓ unsubscribe
┌──────────────────┐            ┌──────────────────┐
│ Echo.private()   │            │ Echo.leave()     │
│ .listen(...)     │            │ clearTimers()    │
│ isConnected=true │            │ isConnected=false│
└──────────────────┘            └──────────────────┘
        │
        ↓ события
┌─────────────────────────────────────────────────────────┐
│  MessageCreated → handleMessageCreated()                │
│  MessageStatusUpdated → handleStatusUpdated()           │
│  UserTyping → handleUserTyping()                        │
│  ...                                                     │
└─────────────────────────────────────────────────────────┘
        │
        ↓
┌─────────────────────────────────────────────────────────┐
│                    Component Unmount                     │
│  onBeforeUnmount() → unsubscribe()                      │
└─────────────────────────────────────────────────────────┘
```

## 🎯 Обработка индикатора "печатает"

```
Пользователь начинает печатать
        │
        ↓ @input
┌──────────────────────┐
│ handleInput()        │
└──────┬───────────────┘
       │
       ↓
┌──────────────────────┐
│ startTyping()        │
│ • isTyping = true    │
│ • sendEvent(true)    │
└──────┬───────────────┘
       │
       ↓ POST /api/conversations/{id}/typing
┌──────────────────────┐
│ Laravel Backend      │
│ broadcast(UserTyping)│
└──────┬───────────────┘
       │
       ↓ WebSocket
┌──────────────────────┐
│ Другие клиенты       │
│ получают событие     │
└──────┬───────────────┘
       │
       ↓
┌──────────────────────┐
│ handleUserTyping()   │
│ • addTypingUser()    │
│ • startTimer(3s)     │
└──────┬───────────────┘
       │
       ↓ через 3 секунды
┌──────────────────────┐
│ removeTypingUser()   │
│ • typingUsers.delete │
└──────────────────────┘

Или пользователь перестает печатать:
       │
       ↓ 1 секунда без ввода
┌──────────────────────┐
│ stopTyping()         │
│ • isTyping = false   │
│ • sendEvent(false)   │
└──────────────────────┘
```

## 📊 Состояния сообщения

```
┌─────────────┐
│  Создание   │
│  сообщения  │
└──────┬──────┘
       │
       ↓
┌─────────────┐
│  'sending'  │ ← Временное сообщение в UI
└──────┬──────┘
       │
       ↓ API запрос успешен
┌─────────────┐
│   'sent'    │ ← Сообщение отправлено на сервер
└──────┬──────┘
       │
       ↓ WebSocket: MessageStatusUpdated
┌─────────────┐
│ 'delivered' │ ← Сообщение доставлено получателю
└──────┬──────┘
       │
       ↓ WebSocket: MessageStatusUpdated
┌─────────────┐
│   'read'    │ ← Сообщение прочитано
└─────────────┘

Или при ошибке:
       │
       ↓ API запрос failed
┌─────────────┐
│  'failed'   │ ← Ошибка отправки
└─────────────┘
```

## 🔐 Security Flow

```
┌─────────────────────────────────────────────────────────┐
│                  Authentication Flow                     │
└────────────────────────┬────────────────────────────────┘
                         │
                         ↓
┌─────────────────────────────────────────────────────────┐
│  1. User Login → получение access_token                 │
└────────────────────────┬────────────────────────────────┘
                         │
                         ↓
┌─────────────────────────────────────────────────────────┐
│  2. Echo инициализация с Bearer token                   │
│     auth: {                                             │
│       headers: {                                        │
│         'Authorization': `Bearer ${token}`              │
│       }                                                 │
│     }                                                   │
└────────────────────────┬────────────────────────────────┘
                         │
                         ↓
┌─────────────────────────────────────────────────────────┐
│  3. Подписка на private канал                           │
│     Echo.private(`conversation.${id}`)                  │
└────────────────────────┬────────────────────────────────┘
                         │
                         ↓
┌─────────────────────────────────────────────────────────┐
│  4. Laravel проверяет права доступа                     │
│     Broadcast::channel('conversation.{id}', fn() => {   │
│       return $user->canAccessConversation($id);         │
│     });                                                 │
└────────────────────────┬────────────────────────────────┘
                         │
                         ↓
┌─────────────────────────────────────────────────────────┐
│  5. Если authorized → подключение успешно               │
│     Если нет → 403 Forbidden                            │
└─────────────────────────────────────────────────────────┘
```
