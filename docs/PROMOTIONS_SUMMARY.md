## 🚀 Как использовать:

1. Откройте раздел **Клиенты → Скидки**
2. Перейдите на вкладку **"Акции"**
3. Нажмите **"Добавить"** для создания новой акции
4. Заполните форму:
   - Название и описание
   - Период действия
   - Минимальную сумму (опционально)
   - Выберите товары-триггеры (опционально)
   - Добавьте товары-подарки
5. Сохраните акцию
